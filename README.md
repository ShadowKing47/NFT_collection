NFT_Collection Creation with Hedera SDK

This project demonstrates how to create NFTs using the Hedera Hashgraph SDK.

Prerequisites
- Node.js (v14 or later)
- NPM (usually comes with Node.js)
- Hedera Testnet account
- Basic understanding of Hedera Hashgraph concepts

## Setup Instructions

1. Initialize the project:
npm init -y

2.Install haderasdk

3.Update .env file according to the instructions provided in the .enc file
